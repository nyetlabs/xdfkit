Map definitions for Bosch ME7 and related ECUs

Each pack is named after the ECU part number it was made for, and fits
one software version only. Check that your image matches before using it.

Files

  PACK.kp          WinOLS map pack
  PACK.xdf         TunerPro definition
  PACK.meta.json   what the XDF can't hold; keep it next to the XDF
                   (TunerPro ignores it, xdfkit uses it to read the XDF
                   back without losing anything)
  PACK.csv         map list
  PACK.json        the definition itself, from which the rest is
                   generated
  PACK-DATE.zip    the files above; DATE (YYYYMMDD) is when the pack last
                   changed. Only the current zip is kept.

Packs

  Top level        hand-made definitions, and tuner subsets
  PACK-tuner.*     the tuning maps of a full definition, filed by
                   category (XDF, metadata and CSV only)
  full/            complete definitions from Bosch data, thousands of
                   maps each

Everything here is generated by xdfkit (https://github.com/nyetlabs/xdfkit)
and may change or disappear without notice. No warranty: check every map
against your image before writing anything to an ECU.
